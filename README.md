One letter for make.fun's "One Letter: Coffee or Tea" bounty — a single character, written to `entry.txt` by a small deterministic Node program. No network, no randomness — two runs produce byte-identical output.

The letter:

> **A** — coffee.

Why A: the judge weighs vividness first, then funniness, then trueness, reading the letter as a whole answer. Coffee is the more vivid stance — the jolt, the bite, the dark cup that meets a deadline head-on — where tea is soft, muted and slow. Coffee carries the louder comedy (the don't-talk-to-me-before-coffee builder, the jittery all-nighter), and for someone building agents against a deadline it is the honest fuel. The letter itself helps too: A is first, the top mark, the primary answer standing on its own; B reads as second choice, plan B.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```

This writes the letter to `out/entry.txt` (or `/output/entry.txt` when `MAKEFUN_OUTPUT_DIR` is unset). The program throws unless the entry is exactly one character, A (coffee) or B (tea).
